# Die Schleife: schauen, entscheiden, handeln

Agenten für alle · Kapitel 2 von 8 · 12 Minuten

Jeder Agent läuft in derselben Schleife: Er schaut, was er weiß, entscheidet den nächsten Schritt, handelt und schaut wieder.

## Ziele

- Triff drei Entscheidungen, als wärst du das Modell.
- Bring den Agenten an sein Ziel.
- Bring die Schritte einer Runde in die richtige Reihenfolge.

## Der Text

### Eine Schleife, immer wieder

In Kapitel 1 hast du gesehen, wie ein Agent in Schritten arbeitet. Jeder Schritt folgt derselben Schleife aus drei Teilen.

Schauen: Der Agent sammelt, was er bisher hat, also deine Anfrage und das Ergebnis seines letzten Schritts. Entscheiden: Das Modell liest all das und wählt den nächsten Schritt, oder es entscheidet, dass das Ziel erreicht ist. Handeln: Der Agent führt den Schritt aus, meist mit einem Tool, und ein Ergebnis kommt zurück. Dann schaut er wieder.

Ein Durchgang durch Schauen, Entscheiden und Handeln heißt Runde. Eine kleine Aufgabe braucht drei oder vier Runden, eine große Dutzende.

### Warum er wieder schaut

Was ein Tool zurückgibt, ist neue Information. Zeigt eine Suche, dass ein Installateur den ganzen Monat weg ist, kann die nächste Entscheidung das berücksichtigen. So ändert ein Agent seinen Kurs, ohne dass man es ihm sagt: Er liest das Ergebnis, bevor er wieder wählt.

### Wann er aufhört

Ein Agent hört aus einem von drei Gründen auf. Das Ziel ist erreicht. Er braucht dich: Er stellt eine Frage oder bittet um deine Freigabe und wartet. Oder er stößt an eine Grenze, etwa eine Höchstzahl an Runden.

### Wie Schleifen schiefgehen

Eine schlechte Entscheidung kostet eine Runde. Zu buchen, bevor überhaupt jemand gefunden ist, bringt zum Beispiel nichts. Schlimmer ist eine Endlosschleife: Der Agent wiederholt denselben Schritt, bekommt dasselbe Ergebnis und wiederholt ihn erneut. Ohne Grenze könnte das ewig so weitergehen, und jede Runde nutzt das Modell, was Zeit kostet und oft Geld. Deshalb zählen echte Agenten ihre Runden und hören an einer Grenze auf.

### Du bist dran

Unten spielst du das Modell. Der Agent schaut, dann entscheidest du, dann handelt der Agent und zeigt dir, was zurückkam. Probier ruhig eine oder zwei schlechte Entscheidungen und sieh, was sie kosten.

## Probier es aus: Du bist das Modell

Du entscheidest jeden Schritt für den Agenten. Sieh dir an, was jede Handlung zurückgibt, und wie eine schlechte Wahl eine zusätzliche Runde kostet.

## Check

Bring die Teile einer Runde der Schleife in die richtige Reihenfolge.

1. Die Anfrage und das Ergebnis des letzten Schritts lesen.
2. Den nächsten Schritt entscheiden oder entscheiden, dass das Ziel erreicht ist.
3. Ein Tool benutzen, um diesen Schritt auszuführen.
4. Lesen, was das Tool zurückgegeben hat.

**Warum:** Schauen, entscheiden, handeln, dann wieder schauen: Was das Tool zurückgibt, wird Teil dessen, was der Agent in der nächsten Runde anschaut.

## Was du jetzt kannst

- Die Schleife beschreiben, in der jeder Agent läuft: schauen, entscheiden, handeln.
- Drei Gründe nennen, warum ein Agent aufhört: Ziel erreicht, er braucht dich oder eine Grenze.
- Erklären, warum Agenten eine Grenze für die Zahl ihrer Schritte brauchen.
