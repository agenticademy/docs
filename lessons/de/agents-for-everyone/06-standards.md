# Standards, einfach erklärt

Agenten für alle · Kapitel 6 von 8 · 14 Minuten

Standards sind vereinbarte Nachrichtenformate, mit denen Agenten, Tools, Apps und Shops von verschiedenen Leuten zusammenarbeiten.

## Ziele

- Steck den richtigen Standard in jede Verbindung einer Reise.
- Öffne eine echte Nachricht und lies, was ihre Felder bedeuten.
- Besteh den Check.

## Der Text

### Warum Standards

Ein Standard ist eine vereinbarte Art, Nachrichten zu schreiben, ein bisschen wie die Form eines Steckers. Wenn alle nach derselben Form bauen, passt jeder Stecker in jede Steckdose. Ohne Standards bräuchte jeder Agent eine eigene Verkabelung für jede App, jedes Tool und jeden anderen Agenten, mit dem er arbeitet. Mit ihnen baut eine Firma ihre Seite einmal und kann sich mit vielen anderen verbinden.

Eine Nachricht ist hier ein kleines, strukturiertes Stück Text, das ein Programm an ein anderes schickt: für wen sie ist, worum gebeten wird, und die Details. In der Simulation siehst du echte.

### Vier Arten von Verbindung

Zwischen der App eines Menschen und einem Agenten: AG-UI (Agent–User Interaction Protocol) überträgt die Unterhaltung, auch die Antwort, während sie geschrieben wird. A2UI (Agent-to-User Interface) lässt einen Agenten einen Bildschirm beschreiben, etwa ein Formular, den die App dann zeichnet.

Zwischen Agenten: A2A (Agent2Agent Protocol) lässt einen Agenten eine Aufgabe an einen anderen übergeben, auch an einen einer anderen Firma, und sie verfolgen, bis sie erledigt ist. ANP (Agent Network Protocol) ist für Agenten, die sich im offenen Web begegnen.

Zwischen einem Agenten und seinen Tools: MCP (Model Context Protocol) lässt einen Agenten Tools finden und nutzen, die jemand anderes betreibt, etwa die Bestellsuche eines Helpdesks.

Zwischen einem Agenten und Shops oder Zahlungen: UCP (Universal Commerce Protocol) gibt Agenten einen gemeinsamen Weg, in einem Shop zu bezahlen, und AP2 (Agent Payments Protocol) lässt einen Agenten nur mit einem Nachweis zahlen, dass du zugestimmt hast.

### Was ein Standard ist und was nicht

Ein Standard ist kein Produkt, keine App und keine Firma. Er ist eine schriftliche Beschreibung von Nachrichten, und jeder kann danach bauen. Diese Standards sind jung: Der erste, MCP, erschien Ende 2024, die meisten sind neuer. Sie ändern sich noch, also prüf beim Lesen über einen Standard das Datum und die Version.

## Check

### Frage 1 von 3

Welcher Standard verbindet einen Agenten mit seinen Tools?

- A2A
- **✓** MCP
- AG-UI

**Warum:** MCP, das Model Context Protocol, ist der Weg, wie ein Agent Tools findet und aufruft, die jemand anderes betreibt. A2A verbindet Agenten mit Agenten, und AG-UI verbindet eine App mit einem Agenten.

### Frage 2 von 3

Wofür ist A2A da?

- **✓** Ein Agent bittet einen anderen Agenten, den jemand anderes betreibt, eine Aufgabe zu erledigen.
- Buttons in einer App zeichnen.
- In einem Shop bezahlen.

**Warum:** A2A (Agent2Agent) lässt einen Agenten eine Aufgabe an einen anderen übergeben und sie verfolgen, bis sie erledigt ist. Bildschirme zeichnen ist die Aufgabe von A2UI, Bezahlen die von AP2.

### Frage 3 von 3

Was ist ein Standard in diesem Sinn?

- Ein Produkt, das man kauft.
- **✓** Ein vereinbartes Nachrichtenformat, nach dem jeder bauen kann.
- Ein Gesetz über KI.

**Warum:** Wie eine Steckerform legt ein Standard fest, wie Nachrichten aussehen, damit Teile von verschiedenen Leuten zusammenpassen. Er ist kein Produkt und kein Gesetz.

## Was du jetzt kannst

- Erklären, was ein Standard ist und warum Agenten Standards brauchen.
- Den Standard für jede Art von Verbindung nennen: Apps, Agenten, Tools, Zahlungen.
- Die wichtigsten Felder einer echten Agenten-Nachricht mit Hilfe lesen.
