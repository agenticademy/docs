# Agenten für alle

Einstieg · Ohne Code · 8 Kapitel · 102 Min.

Für alle, die KI-Agenten verstehen wollen, ganz ohne technisches Vorwissen. Jedes Kapitel erklärt eine Idee in einfachen Worten und lässt sie dich in einer Simulation ausprobieren. Am Ende weißt du, was ein Agent kann und was nicht, erkennst die wichtigsten Risiken und entscheidest, was du einem Agenten überlässt.

## Bevor du anfängst

Nichts. Wenn du schon einmal einen Chatbot benutzt hast, kann es losgehen.

## Am Ende kannst du

- Den Unterschied zwischen einem KI-Modell und einem Agenten erklären.
- Beschreiben, wie ein Agent arbeitet: die Schleife, seine Tools und was er sich merkt.
- In einfachen Worten sagen, wofür Standards wie MCP und A2A da sind.
- Die wichtigsten Risiken erkennen, etwa versteckte Anweisungen, und wissen, wann ein Mensch freigeben sollte.
- Entscheiden, welche Aufgaben du einem Agenten gibst, und ihm einen klaren Auftrag schreiben.

## Kapitel

1. [Ein Modell antwortet. Ein Agent handelt.](01-model-or-agent.md): Der Unterschied zwischen einem KI-Modell, das dir Text gibt, und einem Agenten, der Schritte unternimmt, um ein Ziel zu erreichen.
2. [Die Schleife: schauen, entscheiden, handeln](02-the-agent-loop.md): Jeder Agent läuft in derselben Schleife: Er schaut, was er weiß, entscheidet den nächsten Schritt, handelt und schaut wieder.
3. [Tools: Wie ein Agent die Welt erreicht](03-tools.md): Mit Tools schlägt ein Agent etwas nach und erledigt Dinge, und das Modell kennt jedes Tool nur über sein Etikett.
4. [Gedächtnis und Kontext](04-memory-and-context.md): Was ein Agent bei jedem Schritt sehen kann, ist begrenzt. Was er behält, verwirft und aufschreibt, bestimmt also, was er weiß.
5. [Pläne und Agenten im Team](05-plans-and-teams.md): Große Aufgaben werden in Schritte zerlegt und manchmal auf mehrere Agenten verteilt, die einer leitet.
6. [Standards, einfach erklärt](06-standards.md): Standards sind vereinbarte Nachrichtenformate, mit denen Agenten, Tools, Apps und Shops von verschiedenen Leuten zusammenarbeiten.
7. [Risiken, Sicherheit und Ja sagen](07-risks-and-approval.md): Agenten lesen Dinge, die sie nicht geschrieben haben, und handeln mit Folgen, also brauchen sie Grenzen und im richtigen Moment die Freigabe eines Menschen.
8. [Agenten gut bei der Arbeit nutzen](08-agents-at-work.md): Wählen, was du einem Agenten überlässt, ihn klar beauftragen und prüfen, was er getan hat.
