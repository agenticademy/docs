# Padrões, em palavras simples

Agentes para todos · Capítulo 6 de 8 · 14 minutos

Padrões são formatos de mensagem combinados que deixam agentes, ferramentas, apps e lojas feitos por pessoas diferentes trabalharem juntos.

## Objetivos

- Encaixe o padrão certo em cada conexão de uma jornada.
- Abra uma mensagem real e leia o que seus campos significam.
- Passe na verificação.

## A leitura

### Por que padrões

Um padrão é um jeito combinado de escrever mensagens, um pouco como o formato de uma tomada. Se todos fabricam no mesmo formato, qualquer plugue cabe em qualquer tomada. Sem padrões, cada agente precisaria de uma ligação feita sob medida para cada app, ferramenta e outro agente com que trabalha. Com eles, uma empresa constrói o seu lado uma vez e pode se conectar a muitos outros.

Uma mensagem, aqui, é um pequeno texto estruturado que um programa envia a outro: para quem é, o que se pede e os detalhes. Você vai ver mensagens reais na simulação.

### Quatro tipos de conexão

Entre o app de uma pessoa e um agente: o AG-UI (Agent–User Interaction Protocol) leva a conversa, inclusive a resposta enquanto ela é escrita. O A2UI (Agent-to-User Interface) permite que um agente descreva uma tela, como um formulário, para o app desenhar.

Entre agentes: o A2A (Agent2Agent Protocol) permite que um agente passe uma tarefa a outro, mesmo um operado por outra empresa, e a acompanhe até o fim. O ANP (Agent Network Protocol) é para agentes que se encontram na web aberta.

Entre um agente e suas ferramentas: o MCP (Model Context Protocol) permite que um agente encontre e use ferramentas operadas por outra pessoa, como a consulta de pedidos de um helpdesk.

Entre um agente e lojas ou pagamentos: o UCP (Universal Commerce Protocol) dá aos agentes um jeito comum de finalizar compras numa loja, e o AP2 (Agent Payments Protocol) permite que um agente pague só com a prova de que você concordou.

### O que um padrão é, e o que não é

Um padrão não é um produto, um app nem uma empresa. É uma descrição escrita de mensagens, e qualquer um pode construir com base nela. Esses padrões são jovens: o primeiro deles, o MCP, surgiu no fim de 2024, e a maioria é mais nova. Eles ainda mudam, então, quando ler sobre um, confira a data e a versão.

## Verificação

### Pergunta 1 de 3

Qual padrão conecta um agente às suas ferramentas?

- A2A
- **✓** MCP
- AG-UI

**Por quê:** O MCP, Model Context Protocol, é como um agente encontra e chama ferramentas operadas por outra pessoa. O A2A conecta agentes a agentes, e o AG-UI conecta um app a um agente.

### Pergunta 2 de 3

Para que serve o A2A?

- **✓** Um agente pedir a outro agente, operado por outra pessoa, que faça uma tarefa.
- Desenhar botões num app.
- Pagar numa loja.

**Por quê:** O A2A (Agent2Agent) permite que um agente passe uma tarefa a outro e a acompanhe até o fim. Desenhar telas é trabalho do A2UI, e pagar é do AP2.

### Pergunta 3 de 3

O que é um padrão, neste sentido?

- Um produto que você compra.
- **✓** Um formato combinado de mensagens com base no qual qualquer um pode construir.
- Uma lei sobre IA.

**Por quê:** Como o formato de uma tomada, um padrão diz como as mensagens são, para que partes feitas por pessoas diferentes se encaixem. Não é um produto, e não é uma lei.
