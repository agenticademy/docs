# はじめてのエージェントを作る

初級 · 開発者向け · 全8章 · 152分

エージェントを始める開発者向けです。小さなサポートエージェントを1つ、順を追って作ります。モデル呼び出し、メッセージと状態、グラフ、ツール、エージェントのループ、人の承認を伴うコールバック、ガードレールです。どの章も本物のライブラリを台本モデルと一緒にブラウザで動かすので、キーは不要です。必要なら自分のモデルを接続できます。

## 始める前に

JavaScriptの基礎：関数、オブジェクト、async/await、npmでのパッケージのインストール。

## 修了するとできること

- エージェントに使うLangChain.jsとLangGraph.jsのパッケージを選び、それぞれの役割を理解する。
- チャットモデルを呼び出し、メッセージとグラフの状態を扱う。
- ノード、エッジ、条件付きルーティングでStateGraphを組む。
- zodスキーマでツールを定義し、最小限のReActエージェントを動かす。
- チェックポイントとinterruptBeforeで実行を一時停止して人の承認を待ち、コールバックで記録する。
- ガードレールを加える：入力と出力のチェック、ツールの許可リスト、ステップ上限。

## 章

1. [ライブラリと、ここで動くもの](01-libraries-and-setup.md): エージェントに必要なLangChain.jsとLangGraph.jsのパッケージ、それぞれの役割、そしてブラウザでの動き方。
2. [1回のモデル呼び出し](02-one-model-call.md): LangChain.jsでチャットモデルを呼び出し、返ってくるAIMessageを読み、自分のキーを安全に使います。
3. [メッセージと状態](03-messages-and-state.md): 4種類のメッセージ、会話全体を毎回送る理由、そしてLangGraphがリデューサーで状態をマージする仕組み。
4. [はじめてのグラフ](04-your-first-graph.md): ノードとエッジからStateGraphを組み、条件付きエッジで振り分け、ステップごとに実行します。
5. [ツールとツール呼び出し](05-tools-and-tool-calls.md): zodでツールを定義し、モデルにバインドし、モデルが行うツール呼び出しを処理します。
6. [エージェントのループ：最小限のReActエージェント](06-the-agent-loop.md): モデルのノード、ツールのノード、そして条件付きエッジ1本。エージェントのループ全体をLangGraphのグラフで表します。
7. [コールバックと人の承認](07-callbacks-and-approval.md): コールバックで実行を見守り、危険なツールの前で一時停止して、人が承認または拒否できるようにします。
8. [ガードレール](08-guardrails.md): モデルの周りに置くコードのチェック：入力と出力のチェック、ツールの許可リスト、ステップ上限を、層にして重ねます。
