# ライブラリと、ここで動くもの

はじめてのエージェントを作る · 第1章（全8章） · 15分

エージェントに必要なLangChain.jsとLangGraph.jsのパッケージ、それぞれの役割、そしてブラウザでの動き方。

## 目標

- マップで6つのパッケージを開き、それぞれが何を提供するかを読みます。
- このページでhello-worldを実行し、応答を読みます。
- 確認問題に合格します。

## 本文

### パッケージ

LangChain.jsとLangGraph.jsは、言語モデルを使って開発するためのオープンソースのJavaScriptライブラリです。別々のパッケージに分かれているので、使うものだけをインストールします。

@langchain/coreには共通の部品が入っています。メッセージ、チャットモデルのインターフェース、ツール、コールバックです。@langchain/langgraphは、エージェントをグラフとして動かすランタイムです。状態、ノード、エッジ、チェックポイント、承認のための一時停止を扱います。@langchain/anthropicや@langchain/openaiのようなプロバイダーのパッケージは、1つのプロバイダーのAPI用のチャットモデルクラスを提供します。同じChatOpenAIクラスは、OpenRouter、Hugging Face、NVIDIAのようなOpenAI互換のサービスとも通信できます。zodはツールの入力を記述して検証します。LangChainはzodスキーマを、モデルが読むJSON Schemaに変換します。langsmithは任意で、実行ごとのトレースを記録します。

### なぜグラフのライブラリなのか

エージェントのループは手で書くこともできます。モデルを呼び出し、モデルが求めるツールを実行し、それを繰り返します。第6章では、このループを2つのノードからなるグラフとして組みます。LangGraphは、手書きのループにないものを加えます。ステップごとに保存される状態（これにより実行を人のために一時停止し、あとで再開できます）、並列に動く分岐、そして調べたり図にしたりできる構造です。

langchainパッケージはLangGraphの上に作られていて、ミドルウェア付きの既製のエージェントであるcreateAgentを提供します。この学習パスではまずグラフを手で組みます。そうすれば、あとでそうした補助機能が何をしてくれるのかがわかります。

### インストール

自分のプロジェクトでは：npm install @langchain/core @langchain/langgraph @langchain/anthropic zod。この学習パスでは@langchain/core 1.2.18、@langchain/langgraph 1.5.1、zod 4.6.7を使います。実際のプロジェクトではバージョンを正確に固定してください。これらのライブラリは変化が速いからです。

### ブラウザで違うこと

この学習パスのすべてはブラウザで動くので、LangGraphを@langchain/langgraph/webからインポートします。メインのエントリーポイントはAsyncLocalStorageで設定を入れ子の呼び出しへ渡しますが、ブラウザにはこれがありません。/webでは、入れ子の呼び出しにconfigを明示的に渡し、interrupt()の代わりにブレークポイント（interruptBefore）で実行を一時停止します。それ以外のAPIは同じです。

モデルは既定で台本どおりに動くので、キーは不要で、どの実行も同じ結果になります。この章ではLangChain自身のFakeListChatModelを使います。これは渡した応答をそのまま返します。第2章からは、自分のキーで本物のモデルを接続できます。

## 確認問題

### 質問1/4

HumanMessage、AIMessage、tool()を定義しているパッケージはどれですか？

- @langchain/langgraph
- **✓** @langchain/core
- @langchain/anthropic
- zod

**理由:** @langchain/coreには共通の部品が入っています。LangGraphやプロバイダーのパッケージは、そこからインポートします。

### 質問2/4

LangGraphのグラフをブラウザで動かします。StateGraphはどこからインポートしますか？

- @langchain/langgraph
- langchain
- **✓** @langchain/langgraph/web

**理由:** /webのエントリーポイントは、ブラウザにないAsyncLocalStorageに依存しません。その代わり、入れ子の呼び出しにconfigを明示的に渡します。

### 質問3/4

LangChainのエージェントで、zodは何をしますか？

- **✓** ツールの入力を記述して検証する。LangChainはスキーマをJSON Schemaとしてモデルに送る。
- モデルを呼び出す。
- ステップの間にチェックポイントを保存する。

**理由:** スキーマは2回役に立ちます。モデルはそれを読んでどんな引数を送るかを知り、あなたのコードはそれを使って誤った引数を拒否します。

### 質問4/4

hello-worldでFakeListChatModelを使うのはなぜですか？

- 本物のモデルよりうまく推論するから。
- 本物のモデルはブラウザから呼び出せないから。
- **✓** 決まった応答を返すので、コードがキーもネットワークもなしに、毎回同じように動くから。

**理由:** 偽のモデルを使うと、コードをテストでき、無料で動かせます。本物のモデルもキーがあればブラウザから呼び出せます。それは第2章で見ます。

## これでできること

- LangGraph.jsのエージェントに使うパッケージを選び、それぞれの役割を説明する。
- バージョンを固定してインストールする。
- LangGraphをブラウザで動かすと何が変わるかを説明する。
- 偽のモデルでLangChainのコードを、キーなしで動かす。
