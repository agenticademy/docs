# モデルを理解する

初級 · コード不要 · 全8章 · 120分

AIツールの裏にあるモデルの中身を知りたい人のための学習パスです。テキストがトークンになる様子、モデルが次のトークンを選ぶ仕組み、モデルの作られ方、大きさ、ライセンスで許されることを見たうえで、エージェントのためのモデルを選びます。例ではクローズドなモデルとオープンなモデルを組み合わせ、数値はすべて日付つきのスナップショットから取っています。

## 始める前に

何もいりません。「AIの基本」の最初の2章を読んでおくと役立ちます。

## 修了するとできること

- エージェントが使うモデルの種類と、それぞれの役割を挙げられます。
- トークン、モデルが次のトークンを選ぶ仕組み、温度（temperature）で変わることを説明できます。
- データと事前学習から量子化されたファイルまで、モデルがどう作られるかをたどれます。
- クローズドなモデル、オープンウェイト、オープンソースを見分け、ライセンスの主な条件を読めます。
- リーダーボードを注意深く読み、性能、コスト、ポリシーからエージェント用のモデルを選べます。

## 章

1. [モデルの種類](01-kinds-of-models.md): チャット、推論、マルチモーダル、埋め込み、リランカー、音声、画像生成、ガード、小型のモデルはそれぞれ別の仕事をし、1つのエージェントが複数を使うこともよくあります。
2. [トークン](02-tokens.md): モデルはテキストをトークンとして読み書きし、モデルのファミリーごとにテキストの分け方が違い、料金もコンテキストの上限もトークンで数えます。
3. [次のトークンを選ぶ](03-next-token.md): モデルは次に来うるすべてのトークンにスコアをつけ、スコアを確率に変えて1つをランダムに引き、温度、top-k、top-pはその引き方を変え、ベース、インストラクト、推論の各モデルは違う書き方をするよう学習されています。
4. [モデルはどこから来るのか](04-where-models-come-from.md): モデルは、データと事前学習から、ファインチューニング、フィードバック、蒸留、量子化まで、段階を追って作られ、オープンなモデルでは多くの段階が、中身を調べられるファイルを残します。
5. [サイズとメモリ](05-size-and-memory.md): モデルに必要なメモリは、パラメータの数と1つずつを保存するビット数、それにコンテキスト用の余裕で決まり、MoE（Mixture of Experts）モデルは、トークンごとにパラメータの一部しか使いませんが、すべてをメモリに置いておきます。
6. [オープンなモデルとクローズドなモデル](06-open-and-closed.md): 作り手のサービスを通してしか使えないモデルもあれば、厳しいものから寛容なものまでさまざまなライセンスで重みを公開するモデルもあり、データとコードまで公開するオープンソースのモデルもわずかにあります。
7. [モデルを比べる](07-comparing-models.md): ベンチマークとリーダーボードはモデルを比べる助けになりますが、誤差の幅、エフォート設定、コスト、漏れたテスト、上限に達したテスト、テストを動かすプログラム、誰が実行したかによって、スコアの意味は変わります。
8. [エージェントのためにモデルを選ぶ](08-choosing-for-an-agent.md): モデルを選ぶとは、必須条件を満たさないモデルを外し、残りを1つのエージェントの仕事に合わせて、能力、速さ、課題あたりの料金、コンテキスト、ツール呼び出しの信頼性で比べることです。
