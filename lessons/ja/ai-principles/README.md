# AIの基本

初級 · コード不要 · 全8章 · 111分

AIツールを使っている人や、これから使いたい人のための学習パスです。ページの中で小さなモデルを学習させ、別のモデルが一語ずつ文章を書く様子を見て、何を任せるか、どう頼むか、返ってきたものをどう確かめるかを練習します。最後には、こうしたシステムの仕組みを説明し、判断しながら使えるようになります。

## 始める前に

何もいりません。

## 修了するとできること

- AIモデルとは何か、どのように文章を生み出すのかを、やさしい言葉で説明できます。
- AIが得意なことと失敗しやすいこと、そして自信のある答えでも間違うことがある理由を説明できます。
- AIに何を任せるかを決め、手伝ってもらえるように望むことを伝えられます。
- 返ってきたものを確かめ、個人のデータを渡さず、AIの助けを借りたことを明示できます。
- AIのルールを誰が決めるのかを挙げ、エージェントが自分だけでどこまでしてよいかを選べます。

## 章

1. [AIとは何か、何ではないのか](01-what-ai-is.md): 現在使われているAIシステムの多くは、例からパターンを学び、それを使って新しいものに対する出力を推論します。そうしたシステムは心でも、データベースでも、検索エンジンでもなく、その例があらゆる答えを形づくります。
2. [モデルはどう文章を書くのか](02-how-a-model-writes.md): 言語モデルは確率のリストから引いてトークンを1つずつ書き、温度はその引き方を変えますが、この手順のどこにも言葉が正しいかを確かめる仕組みはありません。
3. [ここは得意、そこは苦手](03-strong-here-weak-there.md): AIは難しいタスクをうまくこなす一方で簡単そうなタスクで失敗し、間違ったことを自信をもって述べることがあり、わからないと言えるときのほうが役に立ちます。
4. [何を任せるか](04-what-to-hand-over.md): タスクは、自分でやる、AIと一緒に進める、AIにやってもらう、エージェントを設定する、のいずれかで進められ、どれにするかは、失敗したときの代償、結果の確かめやすさ、そのスキルを身につけたいかで決まります。
5. [ほしいものを伝える](05-saying-what-you-want.md): 依頼にすき間があると、モデルはそこをありそうな推測で埋めることがよくあるため、良い依頼は、ほしい結果、進め方、ふるまいを書き、あなたにしか出せない事実と例を添えます。
6. [受け取ったものを確かめる](06-checking-what-you-get.md): 整った答えにも、間違った数字、でっち上げの出典、抜けている事実が隠れていることがあり、モデルはあなたが言ったというだけで同意することもあるので、返ってきたものを確かめ、確認を通るまで直していきます。
7. [プライバシー、バイアス、結果に責任を持つこと](07-privacy-bias-ownership.md): AIツールに貼り付けたものは保存されることがあるので、タスクに必要なものだけを共有しましょう。バイアスはデータと設計から生まれ、一部の人に偏って影響します。AIが手伝ったときはそう伝え、送るものには自分で責任を持ちましょう。
8. [ルールを決めるのは誰か](08-who-sets-the-rules.md): 共通の原則、企業の原則、文書にした憲法、法律が、AIの作られ方と使われ方を形づくります。そして、エージェントが自分だけでどこまでしてよいかは、あなたが選びます。
