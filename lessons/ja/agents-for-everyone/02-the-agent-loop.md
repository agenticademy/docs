# ループ：見る、決める、行動する

みんなのためのエージェント入門 · 第2章（全8章） · 12分

どのエージェントも同じループで動きます。わかっていることを見て、次のステップを決め、行動し、また見ます。

## 目標

- モデルになったつもりで、3回判断しましょう。
- エージェントを目標まで導きましょう。
- 1ターンのステップを正しい順に並べましょう。

## 本文

### 1つのループを何度も

第1章では、エージェントがステップごとに動くのを見ました。どのステップも、3つの部分からなる同じループに従います。

見る：エージェントは、ここまでに得たもの、つまりあなたの依頼と前のステップの結果を集めます。決める：モデルがそのすべてを読み、次のステップを選ぶか、目標に届いたと判断します。行動する：エージェントがそのステップを実行し、たいていはツールを使い、結果が返ってきます。そしてまた見ます。

見る、決める、行動するを1回通ることを「ターン」と呼びます。小さな仕事なら3、4ターン、大きな仕事なら数十ターンかかることもあります。

### なぜもう一度見るのか

ツールが返すものは新しい情報です。検索で、ある配管工が今月ずっと不在だとわかれば、次の判断でそれを考慮できます。こうしてエージェントは、指示されなくても進路を変えます。次を選ぶ前に結果を読むからです。

### いつ止まるのか

エージェントが止まる理由は3つのうちのどれかです。目標に届いた。あなたが必要になった：質問をしたり承認を求めたりして待ちます。あるいは、ターン数の上限のような制限に達した。

### ループがうまくいかないとき

よくない判断は1ターンを無駄にします。たとえば、まだ誰も見つかっていないのに予約しても、何も進みません。もっと悪いのは暴走するループです。エージェントが同じステップを繰り返し、同じ結果を受け取り、また繰り返します。制限がなければいつまでも続きかねず、ターンごとにモデルを使うので、時間がかかり、お金がかかることもよくあります。だから本物のエージェントはターンを数え、上限で止まります。

### あなたの番です

下では、あなたがモデルの役をします。エージェントが見て、あなたが決め、エージェントが行動して、返ってきたものを見せます。よくない選択も1つか2つ試して、どれだけ無駄になるかを見てみましょう。

## 試す：あなたがモデルです

エージェントの各ステップは、あなたが決めます。それぞれの行動が何を返すかを見て、よくない選択で1ターン余計にかかる様子を確かめましょう。

## 確認問題

ループの1ターンの部分を正しい順に並べましょう。

1. 依頼と前のステップの結果を読む。
2. 次のステップを決める。または、目標に届いたと判断する。
3. ツールを使ってそのステップを実行する。
4. ツールが返したものを読む。

**理由:** 見る、決める、行動する、そしてまた見る。ツールが返したものは、次のターンでエージェントが見るものの一部になります。

## これでできること

- どのエージェントも回しているループを説明する：見る、決める、行動する。
- エージェントが止まる3つの理由を挙げる：目標に届いた、あなたが必要、制限に達した。
- エージェントのステップ数になぜ上限が必要かを説明する。
