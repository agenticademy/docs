# みんなのためのエージェント入門

初級 · コード不要 · 全8章 · 102分

AIエージェントを理解したいすべての人のための学習パスです。技術的な知識はいりません。各章で1つの考え方をやさしい言葉で説明し、シミュレーションで試せます。最後には、エージェントにできることとできないことを見分け、主なリスクに気づき、何を任せるかを決められるようになります。

## 始める前に

何もいりません。チャットボットを使ったことがあれば準備はできています。

## 修了するとできること

- AIモデルとエージェントの違いを説明できる。
- エージェントの動き方を説明できる：ループ、ツール、覚えていること。
- MCPやA2Aのような標準が何のためにあるかを、やさしい言葉で説明できる。
- 隠れた指示などの主なリスクに気づき、人が承認すべき場面がわかる。
- エージェントに任せる作業を選び、わかりやすい依頼文を書ける。

## 章

1. [モデルは答える。エージェントは行動する。](01-model-or-agent.md): テキストを返すAIモデルと、目標に向けてステップを踏むエージェントの違い。
2. [ループ：見る、決める、行動する](02-the-agent-loop.md): どのエージェントも同じループで動きます。わかっていることを見て、次のステップを決め、行動し、また見ます。
3. [ツール：エージェントが世界に手を伸ばす方法](03-tools.md): ツールは、エージェントが情報を調べたり物事を片づけたりする手段です。そしてモデルは、各ツールをそのラベルでしか知りません。
4. [メモリとコンテキスト](04-memory-and-context.md): エージェントが各ステップで見られるものには限りがあります。だから、何を残し、何を捨て、何を書き留めるかで、知っていることが決まります。
5. [計画と、協力して働くエージェント](05-plans-and-teams.md): 大きな仕事はステップに分けられ、ときには1つのエージェントが率いる複数のエージェントで分担されます。
6. [標準を、やさしい言葉で](06-standards.md): 標準とは、取り決められたメッセージの形式です。これがあるので、別々の人が作ったエージェント、ツール、アプリ、ショップが一緒に動けます。
7. [リスク、安全、そして「はい」と言うこと](07-risks-and-approval.md): エージェントは自分が書いていないものを読み、影響のある行動をとります。だから制限と、適切な場面での人の承認が必要です。
8. [仕事でエージェントを上手に使う](08-agents-at-work.md): エージェントに何を任せるかを選び、わかりやすく依頼し、したことを確認する。
