# 高度なエージェント

上級 · 開発者向け · 全10章 · 205分

エージェントシステムをすでに作れる開発者向けです。大きなグラフとその状態を扱い、CommandとSendでルーティングし、実行を巻き戻して分岐させ、失敗から立ち直り止めどきを知るループを作り、計画のパターンを比べ、長い仕事でディープエージェントのハーネスを動かします。各ラボでは、LangGraph.js 1.5.1が台本どおりのモデルとともにブラウザで本物として動きます。ディープエージェントのハーネスは再現で、画面にもそう表示されます。

## 始める前に

学習パス「エージェントシステムと標準」、または同じ知識：グラフ、ツール、エージェントのループ、チェックポイント、トレース。

## 修了するとできること

- リデューサーとOverwriteでグラフの状態を設計し、並列の書き込みがどう合わさるかを予測できます。
- CommandとSendでルーティングし、サブグラフからチームを組めます。
- チェックポイントから実行を巻き戻し、編集し、分岐させられます。
- 再試行し、補償し、クラッシュ後に再開し、上限、予算、人の判断で止まるループを作れます。
- 計画や計算の使い方のパターンを選び、長い仕事でディープエージェントのハーネスを動かせます。
- 引き継ぎファイル、コンパクション、Storeを使って長い仕事を複数のセッションにわたって進め、その軌跡をコードのルールで評価できます。

## 章

1. [大規模な状態](01-state-at-scale.md): LangGraph.js 1.5.1が状態の1つのキーへの書き込みをどうマージするか。リデューサーのあるStateSchemaフィールドとないフィールド、並列の書き込みの順番、OverwriteとUntrackedValue。
2. [CommandとSend](02-command-and-send.md): ノードはCommandを使えば、状態の更新と次のノードの選択を1ステップで行えます。またSendを使えば、モデルが求める数だけの並列のワーカーに仕事を振り分けられます。
3. [サブグラフとチーム](03-subgraphs-and-teams.md): サブグラフからエージェントのチームを組み、状態の共有のしかたを決め、ストリームの中の名前空間を読み、マルチエージェントのパターンをモデル呼び出しとトークンで比べます。
4. [タイムトラベル](04-time-travel.md): スーパーステップごとにチェックポイントが保存されるので、実行の履歴を読み、過去のステップからリプレイし、過去の状態を編集して、2つ目の結末をフォークできます。
5. [止まらないループ](05-loops-that-survive.md): 再試行ポリシー、タイムアウト、エラーハンドラー、チェックポイントがあれば、ツールが失敗してもプロセスが止まっても、長い実行を続けられます。
6. [止まるループ](06-loops-that-stop.md): ループには、モデルが何をしても効く止め方が必要です。再帰の上限、呼び出しの予算、繰り返し呼び出しの検出器、そして「いいえ」と言える人です。
7. [計画を立てるループ](07-planning-loops.md): Plan-and-execute、ReWOO、LLMCompilerは作業の前に計画を立て、モデル呼び出し、スーパーステップ、時間に違いが出ます。
8. [計算を多く使う](08-spending-compute.md): 評価者・最適化者ループ、リフレクション、best-of-n、木探索は、より良い答えを得るためにモデル呼び出しを多く使います。どれにも予算が必要です。
9. [ディープエージェントのハーネス](09-deep-agent-harness.md): ディープエージェントはToDoリストで計画し、仮想ファイルにメモを残し、仕事の一部を新しいコンテキストのサブエージェントに任せ、指定したツールの前で一時停止します。
10. [長期にわたるエージェント](10-long-horizon.md): 複数のセッションにまたがる仕事には、セッション内のコンパクション、セッション間の引き継ぎファイルとメモリ、そして軌跡全体の確認が必要です。
