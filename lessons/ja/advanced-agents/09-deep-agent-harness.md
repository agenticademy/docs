# ディープエージェントのハーネス

高度なエージェント · 第9章（全10章） · 20分

ディープエージェントはToDoリストで計画し、仮想ファイルにメモを残し、仕事の一部を新しいコンテキストのサブエージェントに任せ、指定したツールの前で一時停止します。

## 目標

- 仕事を始め、エージェントがToDoリストを書いて更新するのを見ます。
- メモの書き込みを承認し、ファイルツリーが育つのを見ます。
- 3つのサブエージェントを並列に動かし、コンテキストの大きさを比べます。
- 確認問題に合格します。

## 本文

### 長い仕事のためのハーネス

ハーネスとは、モデルのループを囲むコードです：プロンプト、ツール、そして各呼び出しが見るものです。LangChainのオープンソースパッケージdeepagentsはその1つで、LangGraphの上に作られています。2025年の発表では4つの部品が挙げられました：詳しいプロンプト、計画ツール、サブエージェント、ファイルシステムです。

### ToDoとファイル

write\_todos({ todos })は毎回リスト全体を受け取り、各項目はpending、in\_progress、completedのどれかで、リストをstate.todosに保存します。ほかには何もしません：利点は、モデルが呼び出しのたびに自分の計画を読み直すことです。1ターンに2回呼ぶと拒否されます。有効にするには、LangChainのtodoListMiddleware()をmiddlewareに加えます。

ファイルツール（ls、read\_file、write\_file、edit\_file、glob、grep）は、グラフの状態の中にある仮想ファイルシステムstate.filesを操作します。サブエージェントはそこにあるメモを読めますし、メモは古いメッセージの要約よりも長く残ります。

### サブエージェント

task({ description, subagent\_type })は、新しいコンテキストでサブエージェントを始めます：自分のシステムプロンプトとdescriptionだけで、呼び出し元のメッセージは1つも含みません。呼び出し元のファイルから始め、書いたファイルは呼び出し元にマージされ、最後のメッセージだけがツールの結果として返ります。1ターンの中の呼び出しは並列に動きます。呼び出し元のツールを持つ汎用のサブエージェントが、最初から用意されています。

### スキル、メモリー、承認

スキルはSKILL.mdファイルを入れたフォルダーです。skills: ['/skills/']を指定すると、プロンプトに各スキルの名前と説明が並び、エージェントはタスクに必要なときだけファイルを読みます。memoryオプションはAGENTS.mdファイルをプロンプトに読み込みます。interruptOnはチェックポインターと組み合わせて、人が各呼び出しを承認、編集、却下するまで実行を一時停止するツールを指定します。このページはブレークポイント（interruptBefore）で一時停止します。interrupt()にはAsyncLocalStorageが必要なためです。

### 足場は少なく

どの部品も、呼び出しのたびにトークンを使います。deepagents 1.12（2026-07-29）はToDoリストをオプトインにし、汎用のシステムプロンプトを空にしました：今のモデルは、それほど指示を必要としません。ハーネス設計についてのAnthropicの記事（2026-03-24）も同じ意見です：新しいモデルが出るたびに、もう必要のない部品を外します。

### このラボでは

再現したハーネスが、架空のショップHaldenの返金クレームについてブリーフを書きます。deepagents 1.16とは違い、todos: trueでリストを有効にし、自分のスキル一覧を持たないresearcherにスキルを見せ、古い汎用のプロンプト行を残し、AGENTS.mdのメモリーはありません。リードはwrite\_fileとtaskの前で一時停止するので、流れを追えます。自分のエージェントでは、エージェントの外の何かを変えるツールの前で一時停止しましょう。

## 試す：調べものの仕事を1部分ずつ

仕事を始めてToDoリストを見て、リードにメモを書かせ、それから3つのサブエージェントを承認してコンテキストの大きさを比べます。

## 確認問題

モデルがこの呼び出しをするとき、リードのコンテキストは約1,400トークンです。researcherはファイルを約600トークン読み、メモを編集し、40トークンの報告で終わります。リードの状態では何が変わりますか？

コード:

```
const lead = createDeepAgent({
  systemPrompt: 'You write briefs.',
  subagents: [{
    name: 'researcher',
    description: 'Researches a cause.',
    systemPrompt: 'Edit the note, then report.',
  }],
});

// The lead's model asks for:
task({
  subagent_type: 'researcher',
  description:
    'Late refunds: /notes/late-refund.md',
})
```

- メッセージにresearcherの会話全体、約650トークンが加わります。ファイルは変わりません。
- メッセージにツール結果が1つ、40トークンの報告が加わります。researcherはコピーを編集したので、ファイルは変わりません。
- **✓** メッセージにツール結果が1つ、40トークンの報告が加わり、編集されたメモがファイルにマージされます。
- リード自身が/notes/late-refund.mdを読むまで、何も変わりません。

**理由:** taskはresearcherを新しいコンテキストで始めます：自分のシステムプロンプトとdescriptionだけで、リードのメッセージは1つも含みません。読んだものはresearcher自身のコンテキストに残ります。最後のメッセージだけがtaskツールの結果として戻るので、リードは約40トークン増えるだけで、researcherが書いたファイルはリードのstate.filesにマージされます。ラボでは、3つのresearcherが何千トークンも読む間に、リードは短い報告3つ分しか増えませんでした。

## これでできること

- middlewareにtodoListMiddleware()を加えてディープエージェントのToDoリストを有効にし、state.todosから計画を読む。
- ls、read\_file、write\_file、edit\_file、glob、grepで、メモや下書きをstate.filesに置く。
- まとまった仕事をtaskのサブエージェントに任せ、戻ってくる報告とファイルを使う。
- interruptOnとチェックポインターで、選んだツールの前でディープエージェントを一時停止し、新しいモデルにもう必要のない足場を外す。
