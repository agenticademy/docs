# Agents for everyone

Beginner · No code · 8 chapters · 102 min

For anyone who wants to understand AI agents, with no technical background needed. Each chapter explains one idea in plain words and lets you try it in a simulation. At the end you can tell what an agent can and cannot do, spot the main risks and decide what to hand to one.

## Before you start

Nothing. If you have used a chatbot, you are ready.

## By the end you can

- Explain the difference between an AI model and an agent.
- Describe how an agent works: the loop, its tools and what it remembers.
- Say what standards like MCP and A2A are for, in plain words.
- Spot the main risks, such as hidden instructions, and know when a person should approve.
- Decide which tasks to give an agent, and write it a clear brief.

## Chapters

1. [A model answers. An agent acts.](01-model-or-agent.md): The difference between an AI model, which gives you text, and an agent, which takes steps to reach a goal.
2. [The loop: look, decide, act](02-the-agent-loop.md): Every agent runs the same loop: it looks at what it knows, decides the next step, acts, and looks again.
3. [Tools: how an agent reaches the world](03-tools.md): Tools are how an agent looks things up and gets things done, and the model knows each tool only by its label.
4. [Memory and context](04-memory-and-context.md): What an agent can see at each step is limited, so what it keeps, drops and writes down decides what it knows.
5. [Plans, and agents working together](05-plans-and-teams.md): Big jobs are split into steps, and sometimes shared among several agents led by one.
6. [Standards, in plain words](06-standards.md): Standards are agreed message formats that let agents, tools, apps and shops built by different people work together.
7. [Risks, safety and saying yes](07-risks-and-approval.md): Agents read things they did not write and take actions with effects, so they need limits and a person's approval at the right moments.
8. [Using agents well at work](08-agents-at-work.md): Choosing what to hand to an agent, briefing it clearly, and checking what it did.
